- Bare withAnimation {} with no value: OverlayTabs.swift:63, :315, :427, :570.

Raw primitives inline: Color.blue (OverlayTabBar.swift:81, OverlayTabs.swift:97,101,206), red literals (OverlayRecordControls.swift:233,237,246,253), .green/.yellow/.orange/.red health (OverlayTabs.swift:244-247), .cyan/.purple (RecordingHUDView.swift:15,26).

- Hit areas: OverlayToolbarButton 24x22 (OverlaySharedChrome.swift:20), HUD finish 22x22, translate pill ~20pt tall (OverlayTabs.swift:98).
- Reduce motion: honored OverlayWindowController.swift:197,212, ResponseView.swift:179; NOT honored: AudioMonitorView.swift:114 repeatForever, LiquidMetalBorder.swift:13 TimelineView(.animation), the four bare withAnimation.

## 4. Proposed minimal UI
Menubar: state-colored dot + monospaced-digit elapsed timer (idle ink 30%, live green, reconnecting amber, error red, saving spinner). Menu: Start/Finish, Settings, Quit.
One overlay panel, no tabs, one vertical split: upper live transcript with speaker chips; lower one ask composer with streaming answer inline above it.
Settings sheet: Soniox key, LLM key, mic picker (virtual devices filtered). First-run card: mic (required), screen recording (optional), one primary button.

View tree:
RTIOverlayPanel > ZStack > PanelSurface(radius 16) + VStack(spacing 16)
  HeaderBar(h32, spacing 8): StateDot(phase, contentTransition symbolEffect replace), ElapsedLabel(monospacedDigit), Spacer, IconButton gear (28x28, label "Open settings")
  LiveTranscriptView (fills, min 240): ScrollViewReader > LazyVStack(spacing 8) > SpeakerTurnRow(chip, text) radius 8; InterimRow italic faint; EmptyState("Nothing yet", action "Start recording")
  AskComposer (spacing 8): AnswerStream(RTIMarkdown, only when non-empty); ComposerRow(radius 8): TextField "Ask about this meeting", SendButton pressed scale 0.97
RTISettingsSheet: SecureField Soniox, SecureField LLM, Picker Microphone (physical only), Button "Save keys".
RTIFirstRunCard: "Allow RTI to hear your meetings", PermissionRow mic required, PermissionRow screen optional, Button "Start using RTI".

Keep: OverlayWindowController, GlobalHotkey, MenuCoordinator (3 items), WindowCoordinator, SpeakerLabels, RTIMarkdown, OverlaySharedChrome, ResizeHandle, Onboarding/AppPermissions, KeychainStore, Audio/*, all Core/, Session/, LLM/, Soniox/.

## 5. Speed
- Full transcript re-coalescing per final segment: OverlayTabs.swift:80-81 makeParagraphs() (:159) runs LiveTranscriptPresentation.rows over ALL entries (Core/Session/LiveTranscriptPresentation.swift:23-60), O(n) per segment; two onChange hooks (:80 count, :81 last id) fire twice. Fix: append incrementally to a cached array.
- Per-token redraw: LLMController.swift:757-760 appends each delta; ResponseView reparses whole markdown per token (:401-402, "▍" appended mutates every frame), onChange scroll seek (:113), GeometryReader preference (:77-84, :91). Fix: buffer deltas on a 50ms tick; render settled paragraphs as static Text, only the tail reparses.
- Unthrottled scroll follow: OverlayTabs.swift:62-67, ResponseView.swift:113-116.
- Always-on timers: 15Hz TimelineView HUD (RecordingHUDView.swift:10) and audio monitor (:14) + 1Hz Combine (:11); 6.7Hz mic meter (OverlayMicControl.swift:43); per-frame shader border (LiquidMetalBorder.swift:13); 2s sentinel poll; analysis scheduler; 240s keep-warm (SessionCoordinator.swift:830).
- Header re-render: OverlayTabBar.swift:46-48 reads AutoAssistController.shared.unseenCount.
- Already right: SessionCoordinator throttles publishes (:790-816); extend to LLM token deltas.
